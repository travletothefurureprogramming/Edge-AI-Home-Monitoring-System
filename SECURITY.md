# Security Policy

## Supported Versions

Only the latest version on the `main` branch receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

As an edge-AI home automation hub that handles local device authentication, network endpoints, and system credentials, security is a top priority.

If you discover a potential security vulnerability within this repository, **please do not open a public issue.** 

Instead, report it responsibly:
* **Email / Contact:** Reach out directly through the maintainer's contact details listed on my profile.
* **Details to include:**
  * Type of issue (e.g., buffer overflow, credential exposure, privilege escalation)
  * Step-by-step instructions or proof-of-concept script to reproduce the issue
  * Potential impact of the vulnerability

We will review the submission, address the issue promptly, and issue a patch or fix in a subsequent update.
